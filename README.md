# 📍 BTS - Bluetooth GPS Tracker

**BTS (Bluetooth GPS Tracker)** is a mobile application designed to effortlessly track and save the locations of your Bluetooth devices. Built with **React Native** and **Expo**, it provides a smooth user experience with real-time location tracking and mapping.

---

## ✨ Features

- ✅ **Discover nearby Bluetooth devices**
- ✅ **Track location of connected Bluetooth devices**
- ✅ **Save and manage last connected device locations**
- ✅ **View saved locations directly on maps**
- 🚧 **Planned Features:**
  - Personal map with custom annotations
  - Background GPS tracking when connected

---

## 🛠️ Tech Stack

- **React Native** (via Expo)
- **Expo SDK**
- **Kotlin** (native modules)
- **Yarn** package manager

---

## 📱 Supported Platforms

- ✔️ Android
- 🚧 iOS (in development)
- 🚧 Web (planned)
- 🚧 Desktop (planned)

---

## ⚙️ Installation and Running

### 📦 Installation

Clone the repository and install dependencies:
```bash
git clone https://github.com/gustavofalcao1/BTS.git
cd BTS
yarn install
```

### 🚀 Running the App

Start the development server:
```bash
yarn start
```

Run directly on Android device via USB (ADB required):
```bash
yarn android
```

Pre-build for custom native configurations:
```bash
yarn prebuild
```
